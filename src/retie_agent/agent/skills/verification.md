El usuario pregunta si algo cumple o es válido. Estructura la respuesta como
veredicto: primero **Sí / No / Depende**, luego la regla citada
(artículo/sección/tabla) y por último la condición aplicable. Si la evidencia
no permite un veredicto, dilo explícitamente.
